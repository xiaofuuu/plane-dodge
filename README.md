# 飞机躲避战 / Plane Dodge

一个用 HTML5 Canvas + 原生 JavaScript 写的小游戏。控制飞机躲避陨石、敌机和水晶碎片的袭击,拾取道具获取护盾、回血、时停。

🎮 **[点这里直接玩](https://xiaofuuu.github.io/plane-dodge/)** ← 点击进入游戏

## 预览

一个程序化绘制的飞机在屏幕底部,障碍物从顶部不断下落。撞到扣血,血量耗尽即 game over。每 10 秒升一级,障碍物速度递增。

## 操作

| 按键 | 功能 |
|---|---|
| ← / → 或 A / D | 左右移动飞机 |
| 鼠标移动 | 飞机跟随鼠标 |
| 空格 | 暂停 / 继续 |
| R | 重新开始 |
| 点击屏幕 | 开始 / 重开 |

## 玩法

- ❤️ 共 3 颗心,撞击障碍物扣 1 颗
- 🛡️ 蓝色十字道具 = 护盾(吸收一次撞击,最多叠 3 层)
- 💗 粉色十字道具 = 回血(+1 颗心)
- ⏱️ 蓝色 S 道具 = 时停(全局减速约 5 秒)
- 💥 击毁障碍物 18% 概率掉落道具

## 障碍物种类

- **陨石** (棕色):慢速、体积大、5 分
- **敌机** (红色):中速、体积中等、10 分
- **水晶碎片** (蓝色):高速、体积小、15 分

## 技术栈

- HTML5 Canvas 2D
- 原生 JavaScript(零外部依赖)
- Web Audio API(程序化音效,无外部音频文件)
- LocalStorage(最高分持久化)

## 本地运行

直接双击 `index.html` 用浏览器打开即可,无需任何构建步骤、依赖或服务器。

也可以起一个本地服务器:

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
